Migrar base de datos

Copia Firestore directamente a un proyecto nuevo conservando los IDs. La base actual nunca se borra ni se modifica.

Esta herramienta migra datos de Firestore. Firebase Authentication se migrará en una etapa aparte para conservar los UID de los usuarios. No cambies todavía la configuración principal de la app.
